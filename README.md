## 先分清你要的是哪种 IP

同一个“西班牙VPS”标签下，卖的东西差别很大。

**机房 IP** 来自数据中心网段，价格最低，建站、跑 API、做欧洲业务都没问题，只是被内容平台判定成“托管商”的概率高。**原生 IP** 指地址注册在西班牙、归属当地运营商，但很多仍挂在机房段下。**住宅 IP** 是从家庭宽带 ISP 分配的地址，查 ASN 出来是普通宽带用户，这也是它贵的原因。

轻树的西班牙页面把这件事摆得比较清楚。六个可用区里，只有马德里 WE 区同时标注“原生 IP 住宅 IP”；马德里 PL、巴塞罗那 C 是原生 IP，马德里 V、马德里 L、巴塞罗那 PL 是机房 IP。退款政策也跟着变：马德里 V 区和 L 区实时开通、销毁退款，其余四个区都是非实时开通、不支持退款。

所以看到“西班牙云服务器”别先比价格，先确认页面写的是哪一种 IP、能不能退。

## 常见问题

**西班牙 VPS 国内延迟多少？**
WePC 马德里节点有推广测评给的三网平均约 280ms、本地约 343ms。这是单一节点的数据，iFog 巴塞罗那和 IONOS 西班牙站的国内延迟资料里没有，不能套用同一个数字。

**住宅 IP 和原生 IP 有什么区别？**
原生 IP 只说明地址注册在西班牙；住宅 IP 还要求这个地址归属家庭宽带 ISP，ASN 查出来是普通宽带用户。轻树六个区里只有 WE 区同时满足两条，WePC 西班牙是双 ISP 住宅，iFog 和 IONOS 都是机房 IP。

**1TB 流量够直播吗？**
按双向计费算，实际可用约 500GB。偶尔播、以短视频上传为主够用；天天长时段直播要自己算码率消耗，超了会限速到 5Mbps。

**能解锁 Netflix 吗？**
有推广文称可以解锁 Netflix、Disney+、YouTube Premium，但没有独立验证。真要拿来当流媒体节点，先用月付试，别按年买。

**能换 IP 吗？**
默认一个静态住宅 IPv4，换 IP 要找客服申请，可能收费。
